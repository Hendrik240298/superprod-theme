# Todoist Dark v0.1.0

First release of the unofficial Todoist-style dark theme for Super Productivity.

## Install

1. Download **todoist-dark.css** below; no ZIP or build needed.
2. In Super Productivity **19.2.0+**, open **Settings → General → Appearance**.
3. Set **Dark Mode → Dark**, then **Install theme** and select the CSS file.
4. Choose **Todoist Dark** if it is not already selected.

## Included

- Todoist-derived charcoal canvas, lighter sidebar and coral-red accents.
- Flat task rows, round native completion controls and system typography.
- Dark menus/dialogs, visible keyboard focus, distinct task states and mobile support.
- No scripts, external assets or changes to task data. Select another theme to undo.

Validated with 12 offline tests, the original Super Productivity 19.2.0 theme
validator, and an isolated real-app smoke test on web build 19.3.1WB. Desktop
Electron and other app screens still need broader hands-on verification.

An independent visual adaptation, not a pixel-perfect Todoist replacement or an
official Doist product. Kanban iframe layout remains owned by the companion plugin.
